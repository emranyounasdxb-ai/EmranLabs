# Project screen tours

The current portfolio uses these on-demand, silent screen tours:

- `edrive-screen-tour.mp4` with `edrive-screen-tour.vtt`
- `inaya-screen-tour.mp4` with `inaya-screen-tour.vtt`

They are 18-second sequences assembled from genuine website captures, with captions describing each screen. They are not recordings of a live transaction. `scripts/prepare-portfolio-media.mjs` generates them from the documented captures. The player loads on demand with `preload="none"` and no autoplay.

The desktop wallpaper is a static optimized image; no background video is loaded by the current workspace.
